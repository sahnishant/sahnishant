# Hi, I’m Nishant 👋

I’m building **[FastBooks](https://www.linkedin.com/company/fastbooks/)** — accounting software designed for Indian retailers, wholesalers, and small businesses in the unorganized market.

Most accounting tools are built around forms, compliance, and accountants. FastBooks is being built around the actual daily workflows of business owners and operators: sales, purchases, inventory, GST, payments, receipts, and reporting.

The goal is simple:

> Make accounting software faster, easier, and more intelligent for Indian businesses.

We are using modern web technologies, strong accounting logic, and AI/ML-assisted workflows to reduce manual work wherever possible.
